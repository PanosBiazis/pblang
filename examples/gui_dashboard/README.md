# GUI Dashboard Example

Small PBIDE-ready GUI project. It demonstrates a dashboard-style native app
without opening a long-running window, so it is safe to run from the IDE.

Files:
- `main.sapp` builds a micro GUI render plan.
- `screens.sapp` describes designer screens for the project.

PBIDE opens it with Code tabs, a Designer app-shell preset, and Browser tabs
for related preview/reference pages.
