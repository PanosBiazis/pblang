Editor

    

      Typing (, [, {, ", or ' auto-inserts the matching close character.
      Line numbers appear in the left gutter; scrolling the editor scrolls the gutter in sync.
    

    
Backend

    

      The IDE talks to http://localhost:8090 by default.
      Override per-tab with ?backend=https://host:port in the URL, or set
      localStorage['pblang.ide.backend'] and reload.
