# Private product workflow snapshot

This branch contains the shared source dependencies and authored libraries/tests for PBTimeline, PBMeasure, PBCompare, PBPalette, PBWords and improvements to PBMedia, PBStencil, PBCircuits and PBOffice Writer. Product sources are separate private repositories under the same GitHub owner. Each product README pins this shared commit.

Clone PBLang and the selected products into sibling directories. Use a compatible PBLang runtime; no binaries, installers, user documents, local build artifacts or credentials are included in this publication. Linux/native model tests, browser readers and generated Android classes have distinct evidence; installed Windows/macOS/mobile releases are not certified.

The publication is an isolated tested snapshot of required library modules. It does not stage or publish the entire concurrently changing live workspace. The existing main branch is unchanged. Targeted product/library tests and strict product builds/manifests passed against this snapshot before publication. Numeric optimization figures are operation-specific local measurements, not general platform guarantees.

See WORDS_AND_SUBTITLE_READING.md, PALETTE_AND_COLOR_WORKFLOWS.md, DOCUMENT_COMPARISON.md, MEASUREMENTS_AND_UNITS.md and PORTFOLIO_TIMELINES.md for contracts and limitations.
