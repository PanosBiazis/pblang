# PBLang portfolio direction — 2026-09-27

The current user priority is all three domains, starting with office, organization and data. The office/data slice is tracked in `PORTFOLIO_FOUNDATIONS.md`; the second slice is tracked in `PORTFOLIO_MEDIA_CIRCUITS.md`.

## Delivered first slice

- PBOffice Writer: native block-document editor, history, search/replace and strict native save/reopen.
- PBJobTracker: local owner-selected status/follow-up insights using the existing service boundary.
- New PBDataLab: CSV/TSV analysis with CLI and native inspector.
- New PBStudy: Writer notes to review cards, explicit dates, review workflow and native deck persistence.
- Four shared libraries: text documents, civil dates, table profiles and study cards.

These are bounded alpha features. Shared Web/Android views are read-only generated snapshots. Physical cross-platform releases, complete suite parity and performance guarantees are not established by this slice.

## Next office/data work

1. Writer multiline layout and supported inline formatting with roundtrip tests, followed by explicit reviewed document-format adapters.
2. Extend the implemented text-only PBOffice Presentations editor with supported shapes/layouts and reviewed interchange adapters.
3. Suite navigation and shared document/session workflows across Writer, Sheets and Presentations.
4. PBDataLab larger streaming datasets, explicit type schemas, selected transformations and interoperable exports, with measured resource budgets.
5. PBStudy editable cards and persistent browser/mobile workflows. Native rating undo, paginated questions/answers and local portable reveal/hide are now implemented.
6. PBJobTracker usable client workflows over the existing service, with functional parity tests.

## Development tools and automation

PBIDE now exposes masked pipeline timing estimates, slack and critical flags through its product facade and a file CLI. Canonical workflow ordering uses adjacency lists with preserved ordering semantics. Continue existing PBIDE and PB-MCP products instead of duplicating them. Candidate features are a project recipe workbench, reproducible test-matrix runner and documentation-to-test inventory. Each needs review of existing modules, a concrete user workflow, bounded execution and real platform evidence. These are proposals, not implemented features or new execution authority.

## Media, creation and education

PBMedia now implements bounded SRT editing, whole-document time shifts and literal WebVTT export. PBCircuits now implements a native voltage-divider calculator and a general bounded resistor-network DC solver. These use the shared subtitle and circuit libraries, with generated read-only Web/Android snapshots. PBStudy establishes one educational product now. PBLesson now implements the common-source lesson-workbench idea as Writer notes -> slides and study cards, with native workspace and portable readers. Executable examples remain a future extension requiring separate scope and review.

## Common acceptance

Every product keeps its own version and lifecycle, canonical PBLang business logic, reusable libraries, strict persisted formats, meaningful tests, portable dependency paths and honest target evidence. Foreign UI editions remain optional and must demonstrate actual behavior. Use AI, GPU, quantum, parallelism and networking only where a concrete workflow benefits and the available implementation is verified. No feature is added merely to list every language capability.

The source catalogs guide product direction only; they do not imply permission to ingest private data, copy unknown-provenance code, train models or publish repositories. This slice was explicitly requested by the user and newly authored; automatic scan-admission contracts remain unchanged.

## Offers, revenue scenarios and table interoperability

The user's commercial target is at least EUR 2,000/month with limited support
time, covering small businesses, developers and consumers. This is a target,
not evidence of demand, signed customers or take-home income.

New PBOffer implements local sales/cost/workload scenarios with a native editable
calculator, CLI, three-market synthetic demo and CSV interchange. Shared
`offer_plan.sapp` provides strict cents parsing, linear-time portfolio arithmetic,
minimum solo sales and explicit workload feasibility. It uses existing
`money.sapp` for display; see `OFFER_PLAN.md`. Web/Android are read-only snapshots.

PBDataLab now has stable literal sorting with Undo and CLI export. PBReconcile
now optionally aligns exact unique headers, preserving the old positional
contract. Shared table transforms gain column projection/reordering and sorting;
dedup/filter eliminate a redundant detached copy. These features reuse existing
libraries and scan-documentation ideas, not private data or third-party source.

Commercial candidates are a small-table workflow kit for businesses, reusable
PBLang recipes for developers, and lesson/template packs for consumers. Prices
and fee/time assumptions require actual validation. These alphas are not yet
general-purpose large-table business software or packaged cross-platform
consumer apps. Priorities before self-service software sales: representative
pilot acceptance, larger datasets where required, installation/update experience,
physical target tests, accessible UI, troubleshooting material and sustainable
support scope. No store, advertising spend, payment integration or customer
outreach was authorized or performed by this implementation.

## Literal document generation

PBMerge adds native/CLI preview and generation of Writer documents from a template
and a header table; PBDataLab exposes the same batch operation. Strict literal
fields, compiled-plan reuse and transparent partial-copy reporting share canonical
libraries. Nine editable business/developer/learning templates provide pilot assets.
See `PORTFOLIO_DOCUMENT_MERGE.md`; Web/Android are readers, not full file editors.

## Palette worksheets and colored mask artwork

PBPalette adds native/CLI palette editing, opaque sRGB pair/matrix metrics, undo and PNG/CSV/Sheets interchange. PBStencil gains transient preview colors and explicit colored artwork export while preserving binary selection masks. Strict shared color functions, palette document/view modules and one-pass-per-color matrix preparation are documented in `PALETTE_AND_COLOR_WORKFLOWS.md`. Web is a metrics reader; Android reader classes are generated only. Installed mobile/desktop packages, alpha/wide-gamut color and full portable editing remain future work.

## Repeating stencil artwork

PBStencil gains editable orientation; PBTile embeds its motifs in saved repeated-pattern recipes with pixel gaps, opaque colors, undo and PNG export. Shared geometry transforms, bounded boolean repetition and strict tile documents support future graphics/education tools. See `PORTFOLIO_TILE_PATTERNS.md`. Web displays exported PNG snapshots; Android currently displays a bounded structural crop. Full browser/mobile editing, vector export and installed target releases remain separate work.

## Literal vocabulary and subtitle text density

PBWords adds local Writer vocabulary worksheets with exact-form frequencies, block locations, complete result pagination and explicit page CSV/Sheets export. PBMedia gains custom-limit density navigation. Shared bounded text metrics preserve Writer statistics while avoiding repeated Unicode indexing. See `WORDS_AND_SUBTITLE_READING.md`. Linguistic segmentation, full portable file editing and installed cross-platform releases remain future work.
