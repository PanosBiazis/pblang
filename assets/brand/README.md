# PBLang visual identity

`icon.svg` is the repository-native, scalable application mark. It contains only
static vector geometry and an accessible title: no scripts, network references,
embedded fonts, animation, or telemetry. It follows the existing PBLang/pbAI
dark-background visual language and has a distinct silhouette.

Use the original SVG for documentation and compatible launchers. Native Windows
ICO, Apple ICNS, Android adaptive-icon packaging and runtime-window integration
remain separate packaging work; adding this source asset does not install an
icon or change an executable's identity or signature.

Original project artwork, covered by the repository's applicable license.
